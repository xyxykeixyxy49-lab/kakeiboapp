# LINE構成デザイナー

公式LINEの構成(シナリオ・分岐・画面)を、マインドマップとトーク画面風プレビューで見える化するWebアプリです。
クライアントとの打ち合わせ中に、その場で編集・コメントすることを想定しています。

## 技術スタック

| 役割 | 使うもの | 選んだ理由 |
| --- | --- | --- |
| 土台 | **Next.js(App Router)+ TypeScript** | 画面とサーバー処理(Notion・Googleドライブを呼ぶAPI)を1つのプロジェクトで作れる。Vercelと同じ会社製で、GitHubにプッシュするだけで自動公開できる |
| 構成図 | **React Flow(@xyflow/react)** | ノードのドラッグ、線のつなぎ替え、ズームなど「図の編集」に必要な機能がそろっている定番ライブラリ |
| 自動整列 | **dagre** | 「自動で整列」ボタンで、左→右の流れにきれいに並べ直すため |
| 画面の状態管理 | **Zustand** | 構成図・プレビュー・編集欄が同じデータを見るための、小さくて分かりやすい仕組み。「元に戻す」も実装しやすい |
| 見た目 | **Tailwind CSS** | LINE風のデザインを素早く作れる |
| データ保存 | Notion API(段階2) | ご指定どおり。サーバー側からだけ呼ぶ |
| 画像保存 | Google Drive API(段階3) | ご指定どおり。サーバー経由で画像を表示するので、ファイルを一般公開しなくてよい |
| 同時表示 | 数秒おきの差分取得(段階4) | Vercelは常時接続(WebSocket)が苦手なため、2〜3秒ごとに変更を取りに行く方式が確実 |
| 公開 | Vercel(段階5) | GitHubへのプッシュで自動デプロイ |

## 進め方

1. ✅ 画面構成+マインドマップ編集+トーク風プレビュー(保存なし)
2. Notion連携(案件・ノードの保存)
3. Googleドライブへの画像保存
4. 共有URL+コメント+同時表示
5. 公開(デプロイ)

## 手元で動かす

```bash
npm install
npm run dev
# → http://localhost:3000 を開く
```

## 秘密情報について

APIキーなどは `.env` に書きます(`.env.example` が見本)。`.env` は `.gitignore` に入っているので GitHub には上がりません。

## フォルダ構成

```
src/
  app/            画面の入口(Next.js)
  components/     画面の部品(左ペイン・構成図・プレビュー・編集・コメント)
  lib/            データの形、ノードの種類(Lステップ/Lメッセージ)、サンプルデータ
  store/          画面全体で共有するデータと操作
```
